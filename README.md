# SOC Home Lab

A hands-on home Security Operations Center (SOC) lab built with Wazuh, Windows Active Directory, Windows 11, Sysmon, Kali Linux, VMware, and MITRE ATT&CK.

## Project Status

?? Lab setup in progress

## Objectives

- Build a virtualized SOC environment
- Configure centralized security monitoring with Wazuh
- Build a Windows Active Directory environment
- Monitor Windows endpoints using Sysmon and Wazuh Agent
- Simulate security attacks in a controlled lab
- Create and test security detections
- Map detections to MITRE ATT&CK
- Perform incident investigation and response
- Document the complete SOC workflow

## Technologies

- Wazuh
- Windows Server
- Active Directory
- Windows 11
- Sysmon
- Kali Linux
- VMware Workstation
- MITRE ATT&CK
